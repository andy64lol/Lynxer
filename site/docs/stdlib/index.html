Standard library

Lynxer ships 27 modules. Each has a .lynx wrapper and a native backend behind the shared native-module ABI; pick one below or from the sidebar.

  • cli — Command-line helpers: arguments, environment, terminal queries and process execution.
  • colorlib — ANSI colour and text-style helpers for terminal output.
  • csv — CSV and TSV parsing, writing and transformation.
  • debug — Assertions, type inspection, structured logging, timers and process metrics.
  • fileIO — File reading, writing, copying, moving and metadata helpers.
  • game — 2-D game toolkit for Lynxer. The drawing, input and window layer is a Rust library built on…
  • image — Image loading, creation, transforms, pixels, and encoding. The backend is a Rust cdylib built with the image…
  • js — Run JavaScript through a Node.js subprocess.
  • json — JSON encoding, decoding, querying and mutation.
  • lua — Embedded Lua 5.4 execution backed by Rust mlua with vendored Lua sources. The module is a cdylib installed as…
  • math — Integer, floating-point, number-theory, rounding, logarithmic and trigonometric helpers.
  • multiprocessing — Run shell commands in parallel.
  • network — HTTP and WebSocket client backed by Rust ureq with rustls and…
  • os — Filesystem, process, environment and platform helpers.
  • path — pathlib-style path manipulation and filesystem helpers.
  • random — Seeded pseudo-random number and character helpers.
  • re — Regular expressions over std::regex with familiar pattern syntax.
  • regex — Extended regular-expression helpers with a named compiled-pattern cache.
  • server — HTTP and WebSocket server backed by Rust axum on tokio. Pair it…
  • shell — Run external shell commands and inspect available shells.
  • sound — The sound module provides audio playback functionality using Rust's rodio and cpal crates.
  • sqldb — The sqldb module provides SQLite database functionality using Rust's rusqlite crate.
  • sys — Runtime, process and platform information.
  • text — Basic string helpers.
  • time — Date and time helpers.
  • tui — The tui module provides terminal UI functionality using Rust's ratatui and crossterm crates.
  • typing — Type conversion and numeric-range predicates.
