About Lynxer

Lynxer is a statically-flavoured, C-style programming language with a standalone native runtime. Source files use the .lynx extension, and every program defines global setup() followed by global main().

The interpreter is written in C++17 and runs programs without a Python runtime. Its standard library ships as native shared libraries — C++ and Rust backends behind one documented C ABI — so a program can open sockets, decode images, play sound, query SQLite or drive a windowed game loop without pulling in a scripting host.

A single --compile command turns a program and everything it imports into one standalone ELF executable that needs nothing from the build tree.

Standalone C++ / Rust runtime Linux amd64 / ARM64 MIT licensed

Basic example

global setup(){
    str name = input("What's your name? ");
}

global main(){
    println("Hello, ", name, "!");
}

Save it as hello.lynx, then run it with ./lynxer/lynxer hello.lynx.

A little more

global setup(){
    importAs("math", "m");
}

global main(){
    for(int i = 1; i < 4; i = i + 1){
        println("sqrt(", i, ") = ", m.sqrt(i));
    }
}

Features

  • C-style syntax with required setup() / main() entry points
  • Standalone native interpreter — no Python or other host runtime
  • Single-file --compile builds that embed the program and its modules
  • Semantics-preserving AST optimizer (--no-opt to disable)
  • 27 standard-library modules with native C++ and Rust backends
  • Frozen native-module ABI for C++ and Rust extensions
  • Enums, structs, classes, vargroups, tuples, codeblocks and pattern matching
  • Tooling: --lint, --ast, --format, --validate-executeable
  • Linux on amd64 and ARM64
