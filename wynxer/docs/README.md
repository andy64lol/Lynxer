# Wynxer documentation

Wynxer is a Lynxer-like language built for websites. It compiles to
JavaScript and WebAssembly for logic, and to HTML and CSS for
presentation. Pages are written in **`.wpf` (Wynxer Page Format)**, a very
simplified DSL, so the author never has to write HTML directly.

Wynxer is a separate binary from `lynxer` and ships its own version
(0.1.0). Everything is generated by the Rust backend.

## Build and run

```bash
make buildWynxer   # (planned) interpreter + every backend
wynxer --version
wynxer build       # compile a project into build/
wynxer serve       # dev server with live reload
wynxer check       # parse + typecheck + WPF validation
wynxer parse page.wpf   # parse a .wpf file and print its structure
wynxer elements    # list every element kind Wynxer understands
```
