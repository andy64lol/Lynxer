# Limitations

Wynxer is pre-alpha. The following are not implemented yet:

- The Wynxer language parser and type checker.
- The JS, WASM, HTML and CSS code generators.
- The dev server (`wynxer serve`).
- The project build (`wynxer build`).
- The language server (LSP).
- The standard library (DOM, fetch, storage, routing, forms, animation).
- The formatter and linter.

See `todo.md` for the full roadmap.
