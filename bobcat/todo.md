# Bobcat todo

Bobcat is a standalone IDE project extracted from Lynxer's former built-in
editors. It provides two independent frontends: **Bobcat CLI** (`cli/`, ratatui)
and **Bobcat IDE** (`ide/`, iced). Lynxer's `--cli-ide` / `--gui-ide` and
`lynxer/ide/` were removed after the extraction, so Bobcat is now the only IDE
for the toolchain. Neither frontend embeds a compiler — both shell out to
`lynxer` / `wynxer`.
